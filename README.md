# Рулетка силы

Онлайн fan-party до 10 игроков. Игра собирает бойца через десять последовательных рулеток, а затем запускает интерактивную битву с личной ультой каждого игрока.

## Состав бойца

1. Одна из 21 аниме-вселенной.
2. Раса только из этой вселенной.
3. Одна из пяти уникальных сил этой вселенной.
4. Физическая сила.
5. IQ и тактика.
6. Скорость.
7. Прочность.
8. Рост.
9. Боевой опыт.
10. Удача.

В каталоге есть One Punch Man, Death Note, JoJo, Dragon Ball, Naruto, Bleach, One Piece, Jujutsu Kaisen, Demon Slayer, Attack on Titan, My Hero Academia, Hunter × Hunter, Chainsaw Man, Black Clover, Solo Leveling, Fullmetal Alchemist, Tokyo Ghoul, Mob Psycho 100, Gurren Lagann, The Eminence in Shadow и Fairy Tail.

## Бой

- Около 1000 базовых HP до модификаторов расы, прочности и роста.
- Обычный контактный урон — примерно 20–30.
- Бойцы двигаются по прямой; направление меняют стены, столкновения и импульс способности.
- Движение автоматическое; обычный удар игрок направляет левой кнопкой мыши по отметке на арене.
- Выпавшую уникальную способность игрок применяет клавишей `E` — ни одна способность не запускается сама.
- Каждый игрок сам активирует уникальный ультимейт своей вселенной клавишей `F`.
- Общего рывка нет: перемещение рывком получают только силы с типом `dash`.
- Все ульты имеют отдельные экранные эффекты, звук, механику и перезарядку.
- 105 обычных способностей имеют уникальные звуковые профили; дальние атаки показывают запуск, трассер и точку попадания.
- Во время арены зациклена CC0-боевая музыка; 21 ульта использует отдельный многослойный звуковой профиль.
- Нет помощников, сундуков, ловушек и молний.
- Зона начинает плавно сужаться ровно после 50 секунд.
- После 90 секунд включается ×1.2 урон, после 120 секунд — ×1.45, чтобы бой не затягивался.
